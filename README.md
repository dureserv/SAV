# SAV
Secure Alarm Vault
1. Secure Access & Dashboard
Colleague Login: A secure login screen. Only authorized team members can access the database.
Central Dashboard: A clean, searchable table of all installations. You can filter by Client Name, Address, Installation Type (Fire / Efraction), or upcoming Maintenance Dates.
Quick Actions: "Add New Installation" (choose Fire or Intrusion) and "Upcoming Maintenance Alerts".

2. Detailed Installation Forms (With Editing/Modifications)
Each installation will have its own dedicated page with structured, editable forms:

Common Info (For All Installations):
Client Name & Contact Info
Site Address (with quick link to Google Maps)
Maintenance Schedule & History Logs
General Notes & Comments

Intrusion Form:
Security Vault Section (Encrypted/Masked): Installer Code, Master Code
Central Unit Type
Number of Detectors & Keyboards
Battery Backup Type
Number of Sirens
Control Room Communication Type & Control Room Name

Fire Alarm Form:
Central Unit Type
Number of Detectors & Control Panels
Battery Backup Type
Number of Sirens
Control Room Communication Type & Control Room Name

3. Document Vault (Uploads)
File Upload Component: Upload building plans (PDF/images) and material specifications directly to each installation record.
File Preview: View uploaded plans directly in the browser without having to download them every time.

4. Security & Protection (Crucial!)
Code Masking: Sensitive fields like Installer/Master codes will be masked by default (e.g., ••••••). A user must click a "Reveal" icon to view them, preventing accidental shoulder-surfing.
Audit Trail: A simple log showing which colleague last modified the installation details.
